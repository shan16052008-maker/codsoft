# C++ Calculator using OOP

## Description
This project is a simple calculator developed using C++ and Object-Oriented Programming concepts. It performs addition, subtraction, multiplication, and division operations.

## Concepts Used
- Classes and Objects
- Functions
- Switch-case
- Loops
- Error handling

## How to Run
1. Compile the program using a C++ compiler
2. Run the executable file
3. Enter values and operations as prompted
